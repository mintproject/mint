# Start here

Before a modeling task, identify your scientific question, region, time period, and expected output. Confirm you have access to the target DYNAMO environment and its required resources.

A **model configuration** describes a runnable model and its inputs, outputs, and parameters. A **dataset** describes data and its resources. A **run** records one execution with selected inputs and parameters.

Discovery and resource registration are different tasks. Registering model metadata does not by itself prepare an executable application; registering dataset metadata does not necessarily upload its files.

Environment-specific access and sign-in instructions are pending verification.

## The catalog home page

The home page is organised by what you want to do: explore models, datasets, regions and variables, or turn a question into a modeling thread. The sidebar's **User Guide** link opens this guide.
