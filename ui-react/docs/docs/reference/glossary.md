# Glossary

- **Model configuration:** a runnable model description with inputs, outputs, parameters, and an execution reference.
- **Dataset/resource:** descriptive data metadata and an individual file or service reference.
- **Standard variable:** a scientific concept connecting data and model contracts.
- **ETL process:** a reusable transformation between input/output contracts.
- **Thread:** a working context for model selection, input assignment, parameters, runs, and results.
- **Provenance:** the record of execution context and resulting artifacts.
