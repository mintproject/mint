# DYNAMO user guide

DYNAMO helps you answer a scientific or planning question by connecting the right models to the right data. This guide shows you how to find what you need, set up a model run, and add your own models and transformations so other people can find and use them.

Start with the description closest to what you do:

- **I want to answer a question with models.** Go to the [Facilitator](facilitator/index.md) guide.
- **I build or look after models and data.** Go to the [Data scientist / model author](data-scientist/index.md) guide.
- **I just want to look around.** Go to [Find models and data](discovery.md). You do not need to sign in to browse.

If you register anything, read [Why the details you enter matter](reference/why-metadata.md) first. It explains why a few extra minutes filling in a form decides whether other people can find your work.
