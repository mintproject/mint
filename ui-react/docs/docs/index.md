# DYNAMO user guide

DYNAMO connects scientific models, datasets, and modeling questions. Start with the role closest to your work.

- [Facilitator](facilitator/index.md): frame a question, select resources, run a model, and inspect results.
- [Data scientist / model author](data-scientist/index.md): prepare runnable models, register models and data, and maintain reusable transformations.
- [Find models and data](discovery.md): shared discovery guidance.

This is the initial documentation scaffold. The role overviews come from the application guide; detailed procedures and a worked example still require verification against a supported application release.
