# Data scientist / model author

You make models, data and transformations findable and usable by other people. DYNAMO can only connect what is described well, so most of your work is describing things carefully: what a model needs, what it produces, and in which unit, format and region.

Read [Why the details you enter matter](../reference/why-metadata.md) first, then work through these pages:

1. [Make a model runnable](make-model.md): what to prepare before you register.
2. [Register a model](register-model.md): the form, field by field.
3. [Register data](register-data.md): what to provide so a dataset can be found.
4. [Connect resources with transformations](transformations.md): register steps that convert one kind of data into another.

When you have finished, try your own model as a facilitator would: start a thread, choose your model, and check that the inputs can be filled with data and the outputs make sense.
