# Make a model runnable

A model can only be run from DYNAMO if it has been set up as an application on the platform that runs it. This step happens before you fill in the registration form, and usually with help from your platform administrator.

Before you register, gather the following:

- **A working model.** Confirm it runs on sample inputs and produces the outputs you expect, so users do not hit your bugs.
- **A list of inputs, outputs and settings.** For each, write its purpose, format, unit and whether it is optional. You will enter these in the form, and clear notes now avoid guesswork later.
- **The application name and version** it runs as. The form asks you to choose it, and it is how DYNAMO knows where to run the model.

If you cannot supply an application yet, you can still describe the model, but a configuration with no component location cannot be run. Say so in the description so people know.

When these are ready, continue to [Register a model](register-model.md).
