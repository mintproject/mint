# Frame a question

The source guide describes a problem statement containing tasks and working threads. Prepare a goal, region, time period, desired outcome, and any driver you want to investigate.

Planned walkthrough: create or reopen a problem statement, add a task/thread, and review the framing before resource selection. Exact labels and prerequisites remain to be verified.

## Existing problem statements

**Modeling → Problem Statements** lists the statements already created. Choose a region to narrow the list or search by name; each card shows its task, sub-task and model counts, its time period, and who last updated it. Use **Add** to start a new one. You must be signed in.
