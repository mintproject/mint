# Facilitator

You take a question, such as "how much groundwater will be available this summer?", and turn it into a model run your team can trust. You do not need to maintain model code. You need to choose sensible models and data, set the scenario, and explain the result.

There are three parts, and framing leads straight into the wizard:

1. [Frame a question](frame-question.md): say what you want to understand, where, and when. DYNAMO suggests models and data, you choose, and it saves your choices as a problem statement.
2. [Run the model wizard](use-model.md): a guided set of steps that takes your choices through to a finished run. You confirm the framing, choose the outcome, models and data, set the values, run, and read the results.
3. [Review results](results.md): read the outcome and compare earlier runs.

Use [Find models and data](../discovery.md) whenever you want to look around first. You must be signed in to start a modeling activity.
