# Facilitator

You are the person who takes a question, such as "how much groundwater will be available this summer?", and turns it into a model run the team can trust. You do not need to maintain model code. You need to choose sensible models and data, set the scenario, and explain the result.

Work through these steps in order:

1. [Frame a question](frame-question.md): say what you want to understand, where, and when.
2. [Set up and run a model](use-model.md): choose models, give each input a dataset, set the values, and run.
3. [Review results](results.md): read the outcome and compare earlier runs.

Use [Find models and data](../discovery.md) whenever you need to look around first. You must be signed in to start a modeling activity.
