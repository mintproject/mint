# Set up and run a model

Once your question is framed, the thread walks you through setting up a run. Work through its steps in order. Each step narrows the next, and the setup is only ready to run when every required input has data.

1. **Framing.** Confirm the goal, region and time period. These choices decide which datasets you will be shown later, so check them now rather than after you have picked models.
2. **Outcome and drivers.** Choose the result you want the model to produce, and, if you want to investigate one, a driver to vary, such as rainfall. DYNAMO may suggest variables, but you confirm the choice, because the outcome decides which models are relevant.
3. **Models.** Choose one or more models. For each, read the description, the region it applies to, what it produces and what it needs. Choose models that produce your outcome and whose inputs you can supply.
4. **Datasets.** Give every required input of every selected model a dataset. Search by name, source or variable, and check the coverage shown: full, partial, unknown, or outside the model's time window. Partial or missing coverage can give misleading results, so prefer full coverage.
5. **Parameters.** Review the settings for each model and enter values for your scenario. Use the defaults, accepted values and units shown. These choices define your scenario, so pick values you can explain to the people who will read the result.
6. **Runs.** Submit the run, set the maximum run time, and refresh to see its progress. The plain-language status tells you whether it is waiting, running, finished or failed.

Look for any missing inputs, incomplete coverage or invalid values before you submit. Fixing them first is faster than waiting for a failed run.

If a model has no dataset available for one of its inputs, see [Troubleshooting](../troubleshooting.md).
