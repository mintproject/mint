# Troubleshooting

For a missing resource, check the scientific variable, region, time coverage, format, and access requirements. For a failed run, preserve the run identifier and visible error before requesting help. Never include access tokens or credentials in a support request.

The completed guide will include verified recovery steps for missing matches, incomplete inputs, invalid parameters, expired sign-in, queued or failed runs, and missing outputs. No environment-specific support channel is assumed.
